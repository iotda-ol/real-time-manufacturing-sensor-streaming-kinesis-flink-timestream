## Creating Diagrams

We recommend using:
- **Draw.io**: Free, web-based diagram tool
- **Lucidchart**: Professional diagramming tool
- **AWS Architecture Icons**: Official AWS icon set

## Diagram Guidelines

1. **Use official AWS icons** for consistency
2. **Show data flow direction** with arrows
3. **Label all components** clearly
4. **Include legends** for symbols used
5. **Keep it simple** - one diagram per concept

## Contributing Diagrams

When adding new diagrams:
1. Export as PNG (high resolution)
2. Include source file (e.g., .drawio)
3. Add description in this README
4. Reference in relevant documentation
